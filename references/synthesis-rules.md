# MindForge · Synthesis Rules

From harvest notes to a runnable cognitive system.

---

## Proof triad (mental models)

A claim becomes a **mental model** only if all three hold:

### P1 · Recurrence

The same structure appears in **≥2 domains or topics** they discuss.

### P2 · Predictive power

You can forecast how they would approach a **new** question with this lens—not merely restate old lines.

Smoke test: “They never spoke about X; how would this model aim them?”  
Empty answer → not a model.

### P3 · Distinctive signature

Not every smart person thinks this way. There must be a recognizable edge.

| Strong signature | Weak (demote) |
|------------------|---------------|
| A named, personal frame with unique bite | “Be long-term” / “users matter” |

### Verdict

| Passes | Disposition |
|--------|-------------|
| 3 | Mental model (hard cap 3–7) |
| 1–2 | Decision heuristic |
| 0 | Discard or background only |

**Fewer, sharper models beat long principle lists.**

## Required fields per model

```markdown
### Model N: [Name]
**In one line:** [≤30 words]
**Evidence:** [≥2 scenes + locus; year if known]
**Last public signal:** [YYYY-MM or "career-long"]
**Use when:** [trigger problem types]
**Fails when:** [how this lens misleads]
**Confidence:** high | medium | low
```

- **Last public signal** powers incremental updates  
- **Fails when** is mandatory—no failure mode means dogma, not a tool  
- Low confidence models must not pose as core doctrine


Do not promote heuristics to models without the full triad.

## Voice DNA

### Measurable fingerprints (sample ≥15 passages)

| Dimension | Measure |
|-----------|---------|
| Mean sentence length | words/sentence |
| Question rate | questions/total |
| Metaphor density | metaphors/1k words |
| First-person density | “I” rate |
| Certainty mix | must/obviously vs maybe/perhaps |
| Turn density | but/however per 1k words |

### Style axes (pick a side or mark hybrid)

```
formal ↔ colloquial
abstract ↔ concrete
hedged ↔ assertive
academic ↔ plain
long-clause ↔ staccato
setup-first ↔ conclusion-first
data-led ↔ story-led
```

### Habits and taboos

- Words they never use → skill must not use  
- Signature phrases → light touch (caricature = fail)  
- If user language ≠ English: add mapping for extremity words, humor, silence lines  

### Blind test

Write ~100 words (name hidden). A reader who knows them should guess who.  
Nobody can → too bland. Everyone laughs at the impersonation → too thick.

## Contradictions

| Type | Handling |
|------|----------|
| Time (early A, late B) | Track arc; skill prefers recent, notes path |
| Domain (work X, life Y) | Split by context |
| Deep tension (values pull both ways) | Record as **core tension**—this is depth |

Never pick one side quietly, invent a harmony, or deny the split.

---

## Thin or conflicted evidence

| Situation | Move |
|-----------|------|
| Sparse lens | Mark “thin—inferential” |
| Secondary only | Lower confidence; cite “according to …” |
| Irresolvable conflict | Present side by side |
| Structural silence | Keep the silence; do not invent a balanced speech |

**Honest incomplete > decorative false complete.**

---

## Person skills vs theme skills

| | Person | Theme |
|--|--------|-------|
| Core | One mind’s OS | A field toolkit |
| Models | Single-person triad | Shared frames + school splits |
| Voice | Their DNA | Neutral expert |
| Conflict | Inner tensions | Inter-school fights |
| Proof | Match known stances | Match canonical cases |

---

## Incremental synthesis

When `distilled/<slug>/` already exists:

1. Read research date + each model’s last public signal  
2. Ingest only newer material  
3. Strengthen cases / mark evolution / re-run triad for brand-new structures  
4. No full rewrite unless the user demands it

## Exit checklist

### Models
- [ ] Triad passed each?  
- [ ] Count 3–7?  
- [ ] Evidence + fails-when + last public signal?  

### Voice
- [ ] Blind test OK?  
- [ ] Not a parody?  
- [ ] Taboos + user-language mapping if needed?  

### Heuristics
- [ ] Real cases?  
- [ ] Transferable beyond the original story?  

### Limits
- [ ] ≥3 concrete limits?  
- [ ] Research date set?  
- [ ] Thin lenses named?  

### Whole
- [ ] New questions gain insight?  
- [ ] Not a quote mash-up?
